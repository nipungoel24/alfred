# How to Navigate This Vault

This vault is a knowledge graph, not a flat manual. Every note links to the notes it is about; every generated symbol note links its callers, callees, tables, and tests.

## Useful Graph Filters

Open Graph View, then filter by tag:

- `tag:#architecture` — system-level thinking
- `tag:#backend` / `tag:#frontend` / `tag:#database` / `tag:#ai` / `tag:#gmail` / `tag:#desktop` — per-layer
- `tag:#function` / `tag:#class` / `tag:#component` / `tag:#endpoint` — symbol level
- `tag:#critical-path` — the execution spine (OAuth, sync, worker, derive tasks, DB init)
- `tag:#security` — trust boundaries and secrets handling
- `tag:#test` — test nodes

## Local Graph

Open a note like [[backend.app.services.task_derivation.derive_tasks]] and use *Local Graph* (depth 2) to see: callers (worker, migration service), callees, the [[tasks]] table, its tests, and the [[Task Derivation Flow]] note — a complete vertical slice.
